# 1. Установка Godot

1. Откройте https://godotengine.org → Download → ваша ОС.
2. Скачайте **Godot 4.7.x — стандартную версию** (не .NET: она нужна только для C#, а C# не экспортируется в веб).
3. Распакуйте архив в папку, например `C:\Godot\`. Установка не нужна — это один файл .exe.
   - Совет: создайте рядом пустой файл `._sc_` — Godot станет «портативным» и будет хранить настройки в этой папке.
4. Запустите Godot.
5. В менеджере проектов нажмите **Create** (Создать):
   - Project Name: `Klubok`;
   - папка — любая пустая;
   - Renderer: **Compatibility**.
6. Нажмите **Create & Edit**.
7. Установите шаблоны экспорта (нужны для сборки игры): **Editor → Manage Export Templates → Download and Install**.
8. Пройдите официальный урок «Your first 2D game» (docs.godotengine.org → Getting started) — 1–2 вечера.

**Проверка:** в правом верхнем углу редактора написано «Compatibility».
