# Шкала «Злость Кота»

Заменяет таймер терпения из v0.1. Сборка злость не тратит — растёт она только от пусков.
Прототип анимации — `04_mockups/video/anger_meter_prototype.mp4`.

## Правила
| Событие | Злость |
|---|---|
| **Неудача:** клубок застрял, упал, кончилась нитка, 15 с без результата | +1 |
| **Ошибка:** громкий удар в зоне слуха Кота | +½ |
| **Ошибка:** предмет попал в Кота | +½ |
| **Ошибка:** зазвенел будильник, фен дует на Кота, огурец | +½ |
| Погладить Кота (раз за уровень, пока злость < 3) | −½ |
| Погладить Кота на «прищуре» — кусается | +½ |
| Победа | сброс к 0 на следующем уровне |

- Шкала 0–4, у каждого целого значения своё лицо: 0 — дремлет, 1 — спокоен, 2 — насторожен, 3 — прищур, 4 — бешенство.
- Старт уровня — 0. От ошибок — не больше +1 за пуск, чтобы один хаотичный пуск не вёл сразу к погрому.
- Дошло до 4 — пуск сразу обрывается, играет видео погрома.
- После видео: предметы на местах, злость = 1, ключевой предмет «подклеен скотчем». Повторный погром на том же уровне — следующий вариант видео.
- «Мурчики» за победу: 3 — злость ≤ 1, 2 — ≤ 2½, 1 — больше.
- Пуск без изменений после неудачи не засчитывается: Кот смотрит с укором, на кнопке — «Сначала что-нибудь поменяй».

## Анимация
| Что | Как |
|---|---|
| Панель | «бумажка» с неровным контуром в верхнем левом углу: круглый портрет Кота + полоса из 4 делений |
| Дыхание | портрет мягко пульсирует (±2 %); чем выше злость, тем чаще: период 2 с → 0,6 с |
| Покачивание | портрет слегка покачивается (±2°) |
| «Кипящий» контур | 3 варианта неровной линии меняются 6–8 раз в секунду |
| Смена лица | «сплющить-растянуть» 0,25 с |
| Заполнение | пружинит (0,6 с) |
| Цвет полосы | Олива → Тёплый свет → Терракота → Тревога; по заполненной части бежит штриховка |
| Подпись события | выезжает «Неудача +1 · клубок не докатился», висит 1,5 с, уезжает |
| Тряска | ошибка — короткая; неудача — слабее |
| Злость ≥ 3 | пар над ушами (3+ облачка) |
| Злость 4 | пульсирует красное свечение, сильная тряска → вспышка → «ПОГРОМ!» → видео |
| Злость снизилась | панель «выдыхает»: короткое сжатие и сердечко |

## Как сделать в Godot
- Сцена `AngerMeter.tscn`: `Control` → `PanelContainer` (фон-«бумажка») → `TextureRect` (5 лиц), `TextureProgressBar` (полоса), `Label` (подпись события), `CPUParticles2D` (пар).
- Логика — узел `CatMood` (автозагрузка). Шкала только показывает его значение.
- Пружина: `create_tween().set_trans(Tween.TRANS_ELASTIC).set_ease(Tween.EASE_OUT).tween_property(bar, "value", v, 0.6)`.
- Смена лица: `Tween.TRANS_BACK` по `scale`.
- «Кипящий» контур: `AnimatedSprite2D` с 3 кадрами или шейдер со смещением по шуму.

```gdscript
# cat_mood.gd — автозагрузка
extends Node
signal anger_changed(value: float, delta: float, reason: String)

const MAX_ANGER := 4.0
var anger := 0.0
var errors_this_run := 0.0
var petted := false

func start_level() -> void:
	anger = 0.0
	petted = false

func start_run() -> void:
	errors_this_run = 0.0

func add_fail(reason: String) -> void:
	_change(1.0, reason)

func add_error(reason: String) -> void:
	var d := minf(0.5, 1.0 - errors_this_run)  # не больше +1 за пуск
	if d > 0.0:
		errors_this_run += d
		_change(d, reason)

func pet() -> void:
	if petted:
		return
	petted = true
	if anger < 3.0:
		_change(-0.5, "погладил Кота")
	else:
		_change(0.5, "Кот укусил")

func is_raging() -> bool:
	return anger >= MAX_ANGER

func after_rage() -> void:  # после видео погрома
	_change(1.0 - anger, "Кот выпустил пар")

func _change(d: float, reason: String) -> void:
	anger = clampf(anger + d, 0.0, MAX_ANGER)
	anger_changed.emit(anger, d, reason)
```
