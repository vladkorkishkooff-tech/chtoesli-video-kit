# История проекта — «git внутри архива»

В архиве лежит настоящий git-репозиторий — скрытая папка `.git`.
Каждый важный шаг — отдельный коммит, версии отмечены тегами (`v0.3`, `v0.4`…).
Этот файл — та же история человеческим языком. **Новые записи — сверху.**

## Как пользоваться
| Хочу | Команда (в папке проекта) |
|---|---|
| увидеть все шаги | `git log --oneline --decorate` |
| что изменилось в шаге | `git show <код шага>` или `git log --stat` |
| сравнить версии | `git diff v0.3 v0.4 --stat` |
| вернуть файл из прошлой версии | `git checkout v0.3 -- 07_plan/roadmap.md` |
| сохранить свой шаг | `tools/save.sh "Шаг N: что сделано"` + запись сюда |

- Без git тоже можно: эта страница описывает каждый шаг.
- **Тяжёлые медиа** (`*.jpg`, `*.mp4`, `*.ogv`, `03_style/references/`, зерно Remotion) в git не хранятся — иначе архив вырос бы вдвое. Их отпечатки — в `MEDIA.sha256`; он входит в каждый коммит, поэтому видно, когда медиа менялись. Проверка, что файлы на месте и целы: `sha256sum -c MEDIA.sha256`. Прошлые версии медиа — в прошлых ZIP.
- Кеш Godot (`09_game/.godot/`) и сборки (`09_game/build/`) в архив и в git не входят — Godot создаёт их сам.
- Версии v0.1 и v0.2 были до git — их описание в `CHANGELOG.md`.

## Журнал

### Шаг 16 · 2026-11-07 · Живой Кот, Lo-Fi музыка, вариативность уровней и UX ускорения
- Свобода решений: расширен инвентарь во всех 12 уровнях (запасные балки, клинья, кубики, батуты) для снятия духоты пиксель-хантинга.

### Шаг 15 · 2026-11-06 · Кот играет с клубком; фен и розетка

### Шаг 12 · 2026-11-06 · Живая реакция Кота
- В пуске Кот слегка поворачивается к близкому клубку и тянется нарисованной лапой; на ошибку и неудачу вздрагивает. Победный прыжок остаётся.
- Это пока визуальные реакции, не физический удар лапой: коллизия Кота и траектория деталей не меняются. Автотест проверяет неизменность коллизии; решения уровней снова проходят.

### Шаг 11 · 2026-11-06 · Тихая музыка Гостиной
- Создана оригинальная синтезированная петля 25,6 с (`tools/make_music.py`, без чужих семплов); в игре она тихо повторяется.
- Отдельная кнопка включает и выключает музыку, выбор сохраняется; общая кнопка звука по-прежнему отключает всё. Во время погрома музыка ставится на паузу и возобновляется после него.
- Автотесты проверяют независимый переключатель, цикл и паузу погрома; звучание — черновик, его нужно прослушать и оценить при тестировании.

### Шаг 10 · 2026-11-06 · Более длинные цепочки и допуск финала

- `test_runner` теперь проверяет допустимость каждого эталонного решения в конструкторе и количество доступных деталей, наряду с 10 повторами, позами Кота и частичными решениями.

### Шаг 9 · 2026-11-06 · Отмена действий конструктора

### Шаг 2 · 2026-11-04 · Godot-проект: физика, 4 уровня, автотест
- Новая папка `09_game/` — проект Godot 4.7.2 (GDScript, Compatibility, Godot Physics 2D).
- Детали конструктора: балка (капсула 12 px, 1–6 клеток, 15°, гвоздь → PinJoint2D), кубик, клин, клубок (разматывается, худеет до 65 %, нитка-след), Кот (позы по злости, пятно света, слух 260 px).

- Автотест `tests/test_runner.tscn`: решение каждого уровня — **10 из 10 побед, все пуски совпадают бит в бит**, при любой позе Кота; без деталей — неудача.
