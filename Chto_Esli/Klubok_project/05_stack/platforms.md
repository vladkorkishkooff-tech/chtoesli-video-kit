# Площадки

**Утверждены:** Яндекс Игры, CrazyGames, itch.io. **Следующие:** VK Игры и Одноклассники — одной сборкой. Android — RuStore, затем Google Play.
Все веб-площадки получают одну и ту же веб-сборку; разницу между ними берёт на себя Playgama Bridge (`sdk.md`).

## Порядок
1. **itch.io** — закрытые тесты по ссылке с паролем, начиная с первого прототипа.
2. **Яндекс Игры** — первый публичный выпуск.
3. **CrazyGames** — Basic Launch → Full Launch.
4. **VK Игры + Одноклассники** — та же сборка, модерация строже.
5. **RuStore**, затем **Google Play** — Android.

## Сравнение веб-площадок
| | Яндекс Игры | CrazyGames | itch.io | VK Игры + ОК |
|---|---|---|---|---|
| Стоимость | бесплатно | бесплатно | бесплатно | бесплатно |
| SDK | обязателен | для Full Launch | не нужен | VK Bridge обязателен |
| Проверка | модерация | 2 этапа: Basic → Full | нет | модерация каталога |
| Деньги | реклама, покупки | доля от рекламы — после Full Launch | продажа или «сколько не жалко» | реклама, товары за голоса — после попадания в каталог |
| Вес | ≤ 100 МБ без сжатия | старт ≤ 50 МБ (≤ 20 МБ — для главной на телефонах), всего ≤ 250 МБ, ≤ 1500 файлов | — | — |
| Особое | Game Ready, пауза, язык через SDK | сразу в игру, без меню; работает с AdBlock | удобно для тестов | обучение, ≥ 10 мин игры, качество графики, обязательная монетизация |

## Общие правила
- Внутри игры — никаких логотипов, ссылок и упоминаний других площадок: этого требуют VK (4.2.6) и CrazyGames (условие выплат).
- Одна веб-сборка для всех; особенности площадки — через `Bridge.platform.id` (`sdk.md`).
- Прогресс — в хранилище площадки через `Bridge.storage`.

## Яндекс Игры — первый публичный выпуск
- Публикация бесплатная: регистрация в консоли разработчика по Яндекс ID и договор.
- Без SDK опубликовать нельзя. Официального плагина для Godot нет — берём Playgama Bridge (есть в списке сторонних решений у Яндекса).
- Главные требования (номера — из правил Яндекса):
  - 1.2.2 — играть можно без входа в аккаунт, прогресс сохраняется;
  - 1.3 — звук выключается, когда вкладка неактивна;
  - 1.6.1.1 и 1.6.1.5 — на телефоне полный экран и всё управление жестами;
  - 1.12 — подключена монетизация (реклама или покупки);
  - 1.14 — без ошибок при повороте, сворачивании, показе рекламы;
  - 1.19.2 — сигнал «игра готова» (Game Ready), когда уже можно играть;
  - 1.21 — все файлы вместе ≤ 100 МБ без сжатия;
  - 1.22 — `index.html` в корне архива, имена файлов без пробелов и кириллицы;
  - 1.23 — интерактивный ИИ в игре запрещён, заранее сгенерированные материалы — можно;
  - 2.14 — язык определяется автоматически через SDK;
  - 4.1 и 4.7 — реклама только через SDK Яндекса; на время рекламы — пауза игры и звука.
- Пошагово — `06_manuals/05_publish_yandex.md`.

## CrazyGames
- Бесплатно, заявка через developer.crazygames.com, Godot поддерживается, выплаты от 100 €.
- **Basic Launch:** 7–21 день на ограниченной аудитории. SDK CrazyGames не нужен, проверка базовая, монетизация выключена.
- **Full Launch:** если метрики хорошие (среднее время игры, переход в игру и др.) — игра выходит для всех. Нужен SDK и полная проверка; включается доля от рекламы.
- Вес: стартовая загрузка ≤ 50 МБ (≤ 20 МБ — чтобы попасть на главную на телефонах), всего ≤ 250 МБ (без SDK — ≤ 50 МБ), ≤ 1500 файлов. Стартовая загрузка считается от начала загрузки до первого сигнала начала игры.
- Godot загружает весь пакет `.pck` при старте, поэтому видео погрома попадают в стартовую загрузку. Решение: ролики ≈ 2 МБ, а для CrazyGames — догрузка роликов отдельным пакетом после старта (`06_manuals/06_video_cutscenes.md`, раздел 8).
- Full Launch: игрок сразу попадает в игру (без титульного экрана), игра работает с включённым AdBlock, реклама — только через SDK CrazyGames.
- Эксклюзив: 2 месяца после Full Launch игра только на CrazyGames → +50 % дохода. Нам не подходит: к тому времени игра уже будет на Яндексе.
- Пошагово — `06_manuals/07_publish_crazygames_vk.md`.

## itch.io
- Бесплатно, без проверки, SDK не нужен.
- Закрытый тест: страница в режиме **Restricted** — видят только те, кому вы дали доступ (например, ссылка + пароль).
- Позже — публичная страница: веб-версия и ПК-сборка (Windows).
- Пошагово — `06_manuals/04_export_web.md`.

## VK Игры и Одноклассники — следующие
- Публиковать может любой пользователь, бесплатно. Одна игра — сразу во ВКонтакте и в Одноклассниках (привязка OK ID).
- Нужен VK Bridge — Playgama Bridge подключает его сам (площадки `vk` и `ok`).
- Файлы игры должны быть доступны по HTTPS; у VK есть свой хостинг для игр.
- Модерация каталога строже, чем у Яндекса:
  - 4.2.1 — в каталоге только игры с монетизацией (товары за голоса или реклама);
  - 4.2.4 — понятное управление или обучение;
  - 4.2.5 — графика на уровне популярных игр жанра;
  - 4.2.6 — никаких логотипов и упоминаний других площадок и соцсетей;
  - 4.2.7 — прохождение дольше 10 минут;
  - 2.2.1 — VK Bridge подключён и инициализирован;
  - игра авторизует игрока по параметрам запуска и проверяет их подпись — открытый вопрос (`07_plan/open_questions.md`).
- Деньги: регистрация в кабинете выплат; доход — только после модерации и попадания в каталог, до этого реклама показывается в тестовом режиме.
- Пошагово — `06_manuals/07_publish_crazygames_vk.md`.

## Android
- **RuStore** — регистрация и публикация бесплатные, принимает APK и AAB. Монетизация — только для ИП и юрлиц.
- **Google Play** — разовый взнос $25, только AAB и релизный ключ подписи.
- Управление: перетаскивание пальцем, кнопки и предметы ≥ 48 dp, поворот — кнопками у выбранного предмета, масштаб — щипком.
- Нативная сборка работает быстрее веб-версии. Пошагово — `06_manuals/03_export_android.md`.

## ПК
- itch.io — бесплатно (Windows, позже macOS и Linux).
- Steam — платно ($100 за игру); позже, если будет спрос.
