# «Клубок» — папка проекта

**Версия игры:** v0.7.1 · 2026-11-07 — живой Кот, Lo-Fi музыка, вариативность уровней, ускорение 1×/2× и след клубка

Физическая головоломка в духе «Заработало!» (Crazy Machines) в стиле «Свет».
Сосед должен успокоить Кота — докатить до него клубок по балкам, которые игрок строит на поле, и цепочкой из домашних предметов.
Каждая неудача злит Кота. Шкала злости заполнилась — видео погрома: Кот громит главный предмет локации.

## Как пользоваться
- Эта папка — единый источник правды по проекту. Каждая итерация — новый архив: `Klubok_project_v0.3.zip`, `v0.4` и т. д.
- **Поиграть:** `09_game/` — проект Godot 4.7.2 (F5), или веб-сборка `Klubok_web_v0.7.zip`. Как открыть, управление, тесты — `06_manuals/08_prototype.md`.
- **История внутри архива:** в папке лежит git-репозиторий (скрытая `.git`) — каждый шаг отдельным коммитом, версии — тегами. Человеческим языком — `HISTORY.md`; там же команды.
- Что изменилось в версии — `CHANGELOG.md`.
- Чтобы продолжить работу в новом чате, прикрепите последний ZIP.
- Следующие шаги — `07_plan/roadmap.md`, раздел «Сейчас».

## Ключевые решения
| Тема | Решение |
|---|---|
| Жанр | физическая головоломка: нарисуй балки, поставь предметы → «Пуск» → смотри, что вышло |
| Главный акцент | честная физика и её понятность для игрока |
| Подсказки | подсветка светом внутри мира |
| Кот | активный персонаж: следит, бьёт лапой, пугается, лезет в коробку, катается на пылесосе |
| Шкала злости | растёт от неудач (+1) и ошибок (+½), 5 лиц, живая анимация |
| Погром | заранее сделанное видео 4–8 с (.ogv), можно пропустить |
| Звук | короткие звуки и мурчание; синтезированные звуки и музыкальный черновик Гостиной; финальное звучание — вопрос 14 |
| Конструктор | простые детали в каждом уровне: балка (рисуется пальцем от точки к точке, 1–6 клеток, углы через 15°), гвоздь (качели, маятник), кубик, клин |
| Предметы | бытовые: мандарин, тапок, подушка, гирлянда, ложка, скалка, будильник, мыло, фен, робот-пылесос, зонт, бельевая верёвка + «кошачьи»: коробка, лазерная указка, огурец |
| Формат | 2D |
| Движок | Godot 4.7 (стабильная 4.7.2) + GDScript |
| Физика | встроенная Godot Physics 2D (Rapier не подходит для веб-площадок) |
| Рендерер | Compatibility |
| Площадки | утверждены: Яндекс Игры (первый публичный выпуск), CrazyGames, itch.io (закрытые тесты с первого прототипа); следующие — VK Игры и Одноклассники; Android: RuStore, Google Play; ПК: itch.io |
| SDK площадок | Playgama Bridge — один плагин сам подключает SDK каждой площадки (`05_stack/sdk.md`) |
| Стиль | «Свет»: плоский 2D, неровный контур, ночь + тёплый свет, зерно |
| Мемы | изредка, только перерисованные в нашем стиле |
| Сюжет | позже |
