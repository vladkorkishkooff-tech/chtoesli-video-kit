# Видео-прототипы (Remotion)

Исходники роликов из `04_mockups/video/`. Remotion собирает видео из кода на React — удобно для аниматиков и прототипов интерфейса.

| Композиция | Файл | Что это |
|---|---|---|
| `AngerMeter` | `src/AngerMeter.tsx` | шкала злости, 13 с |
| `RageAnimatic` | `src/RageAnimatic.tsx` | видео погрома «Ёлка», 8 с |

Общие части (зерно, виньетка, цвета) — `src/common.tsx`. Картинки — `public/`: лица Кота (`faces/`), зерно (`grain/`), ключевые кадры (`kf/`).

## Запуск
1. Установите Node.js 20 или новее: https://nodejs.org
2. В этой папке: `npm install`.
3. Просмотр и правки в браузере: `npm run studio`.
4. Рендер: `npm run render:meter` и `npm run render:rage` → папка `out/`.
5. В формат для Godot:
   `ffmpeg -i out/rage_tree_animatic.mp4 -vf "scale=-1:720" -q:v 5 -g:v 64 rage_livingroom_tree_01.ogv`

## Ролик для другой локации
1. Нарисуйте 3 ключевых кадра (напряжение, погром, стоп-кадр), 16:9, не меньше 1280×720, и положите в `public/kf/`.
2. Скопируйте `RageAnimatic.tsx`, поменяйте имена картинок и подпись (например, «Кружка больше не кружка»).
3. Добавьте композицию в `src/Root.tsx` и отрендерьте.

`remotion.config.ts` — обход несовместимости сборщика с новыми версиями TypeScript. Если мешает — удалите файл.
