# «Что если?» — ролик в стиле «тушь и глина»

## 0. Сначала прочитай (обязательно, целиком)
1. `CRAFT.md` — как думать, приёмы, цифры. **§0 — жёсткие запреты на искажение и кривизну. Они сильнее любой идеи.**
2. `PROJECT.md` — конвейер, формула ролика, правила монтажа, чек-лист приёмки. Пути в нём для Windows-машины автора. Здесь все команды запускаются из `studio/`, пути относительные (§3 ниже).
3. Образцы:
   - `refs/style_a_night_sheet.jpg` — рисовка A «Ночь», исходник `studio/ep_blackout_calm.html`;
   - `refs/style_b_paper_sheet.jpg` — рисовка B «Бумага», исходник `studio/ep_style_b_paper.html`;
   - `refs/cover_example.jpg` — утверждённая обложка.

Эталона пока нет: пользователь выбирает рисовку. Если в задаче рисовка не указана, спроси.

## 1. Окружение (один раз)
```bash
sudo apt-get install -y ffmpeg fonts-dejavu      # если нет
npm i playwright && npx playwright install --with-deps chromium
pip install faster-whisper                       # слова по голосу; без него — черновая раскладка
```
- `prender.cjs`, `text_check.cjs` и `shot.cjs` берут playwright из `node_modules`.
- Нужен другой путь — `PLAYWRIGHT_PATH=<путь к playwright>`.
- Свой chromium — `PW_CHROMIUM=<путь к бинарю>`.

Проверка: `node shot.cjs ep_blackout_calm.html /tmp/t.png 12` должен дать кадр с героем у ванны.

## 2. Как устроен ролик (коротко)
- Один ролик = одна страница `studio/ep_<id>.html`, SVG 1080×1920. Кадр — чистая функция времени. Страница отдаёт `window.__seek(t)`, `window.__duration` и `window.__audioWav()` (звуки).
- Время сцен — `data/<id>.timings.json`, слова диктора — `data/<id>.words.json`. События в странице привязаны к словам: `W('s03','Набери')`.
- Движок:
  - `lib/oneline.js` — камера, слои, sfx;
  - `lib/brush.js` — кисть;
  - `lib/inkclay.js` — `ink` / `clay` / `note` (пометки на карточках);
  - `lib/folk.js` — герой на шарнирах.
- Звук — только настоящие записи `foley/*.wav`: `sfx(t, 'file:foley/<имя>.wav', {gain: 1})`.

## 3. Конвейер (всё из `studio/`)
| # | Шаг | Команда | Готово, когда |
|---|---|---|---|
| 1 | Факты | `../episodes/<id>/sources.csv` (МЧС, ready.gov, ВОЗ, Красный Крест) | у каждой цифры есть ссылка |
| 2 | Сценарий | `../episodes/<id>/script.json` по формуле PROJECT.md §4 | **пользователь написал «ок»** |
| 3 | Черновые тайминги | `python tools/timings_from_voice.py ../episodes/<id> --estimate` → `python tools/word_times_portable.py ../episodes/<id>` → скопировать оба json в `data/<id>.*.json` | можно собирать страницу до голоса |
| 4 | Страница | скопируй `ep_blackout_calm.html` (A) или `ep_style_b_paper.html` (B) → `ep_<id>.html`, перепиши мир, хореографию, камеру, пометки, звуки | кадры `shot.cjs` без нарушений CRAFT §0 |
| 5 | Черновой рендер | `node tools/text_check.cjs ep_<id>.html` → `node tools/prender.cjs ep_<id>.html ../renders/<id>_draft.mp4 --workers 4` | ролик без голоса, со звуками действий — пришли пользователю на просмотр |
| 6 | Голос | пользователь присылает `s01.mp3 … s09.mp3` (ElevenLabs «Sergey Lebedev», id `XuEV9VY3VUASYgJVNBh0`, модель eleven_v3) → положи в `../episodes/<id>/voice/` | файл на каждую сцену |
| 7 | Точные тайминги | `python tools/timings_from_voice.py ../episodes/<id>` → `python tools/word_times_portable.py ../episodes/<id>` → снова скопировать в `data/` | слова распознаны правильно (сверь с текстом) |
| 8 | Финал | `text_check` → `prender` → `python tools/finish_mix.py <рендер.mp4> ../episodes/<id>/timings.json ../episodes/<id> <выход.mp4>` → `ffmpeg -i <выход> -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a copy -movflags +faststart ../renders/<id>.mp4` | −16 LUFS, голос не обрезан |
| 9 | Приёмка | чек-лист PROJECT.md §9 + проверка поз CRAFT §0 | в отчёте прямо сказано, что проверено, а что нет |

Новый звук действия:
1. Найди запись на `mixkit.co/free-sound-effects/<слово>/`. Лицензия разрешает коммерцию.
2. Скачай превью mp3 в `foley/src/<id>.mp3`.
3. Добавь строку в `CUTS` в `tools/foley.py` и запусти его.

Синтетические звуки и музыку не использовать.

## 4. Цикл доводки (CRAFT §6)
1. Сделай лист кадров: `ffmpeg -i r.mp4 -vf "fps=1/2.5,scale=200:-1,tile=11x2" -frames:v 1 sheet.jpg`. На каждый кадр задай три вопроса: что делает герой и зачем? читается ли текст? есть ли нелепость или кривизна?
2. Каждую найденную проблему запиши правилом в CRAFT.md.
3. Исправь её минимальной правкой в одном месте.
4. Сними `shot.cjs` именно в этих моментах.
5. Только потом делай полный рендер.

## 5. Всегда / никогда
- **Всегда:**
  - каждое действие попадает на слово диктора;
  - один мир, по которому ездит камера, зум ≤1,4×;
  - подписи маленькие, пометки на карточках;
  - развязка рядом с героем;
  - вещи узнаются по деталям;
  - всё детерминировано от `t`.
- **Никогда:**
  - не искажать героя, линии и текст (CRAFT §0);
  - не менять внешность героя без запроса;
  - не держать позу без смысла дольше 1,5 с;
  - не стоять на мебели;
  - не ставить кружки и треугольники вместо вещей;
  - не добавлять музыку, нарастания и синтетические звуки;
  - не рендерить финал без утверждённого сценария;
  - не называть ролик готовым, не просмотрев кадры.
